Подсказки если их можно считать таковыми
=====ОСНОВНЫЕ КОМАНДЫ И КИТА НА КОТОРЫХ ВСЕ СТОИТ=====
git init -> для создания репозитория
git status -> проверяет состояния и лучше проверять почаще лишним не будет
git add . -> добавляет изменения в так называемый "индекс"
git add <file> -> добавляет конкретный файл
git commit -> для сохранения
git commit -m <msg> -> сохранение но флаг -m позволяет написать сообщение что лучше написать
git push -> для отправки
git pull -> для получения
git clone <link> -> для копирования репозитория
=====ДЛЯ РАБОТЫ С ВЕТКАМИ=====
branch перевод ветка
значит
git branch -> список веток
git branch <имя ветки> -> создает ветку с именем <имя ветки>
git checkout <имя ветки> -> для переключения на ветку
git branch -d <имя ветки> -> для удаления ветки
=====СЛУЖЕБНЫЕ КОМАНДЫ=====
git remote add origin <link> -> привязывает репозиторий
=====ТЕ КОТОРЫЕ ЕЩЕ НЕ ИСПОЛЬЗОВАЛ НО ОНИ ВАЖНЫ=====
git merge -> для слияния
git log -> история коммитов
